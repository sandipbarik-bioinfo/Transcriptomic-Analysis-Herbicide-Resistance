# Transcriptomic Analysis of Pinoxaden Resistance in *Apera spica-venti*

RNA-seq transcriptomic analysis investigating gene-expression changes associated with the development of pinoxaden resistance in *Apera spica-venti*.

## Project Overview

This project investigates transcriptomic responses associated with pinoxaden herbicide resistance using publicly available RNA-sequencing data.

The analysis integrates differential gene-expression analysis, transcriptomic comparison between susceptible and resistant populations, meta-analysis, candidate gene identification, sequence-based annotation, and functional interpretation.

## Objectives

- Characterize transcriptomic responses to pinoxaden treatment.
- Identify differentially expressed genes between susceptible and resistant populations.
- Integrate differential-expression results across relevant comparisons.
- Identify candidate genes associated with pinoxaden resistance.
- Perform sequence-based and functional annotation of candidate transcripts.
- Investigate biological pathways and functions associated with resistance.

## Dataset

The primary expression dataset used in this analysis was obtained from the NCBI Gene Expression Omnibus (GEO), accession **GSE204857**.

The dataset contains transcriptomic data from susceptible and resistant *Apera spica-venti* populations under control and pinoxaden-treated conditions.
